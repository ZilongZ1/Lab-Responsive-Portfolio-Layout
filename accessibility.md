I used Google PageSpeed Insights to audit my portfolio website on both mobile and desktop devices. The purpose was to check accessibility and identify possible improvements.

# Accessibility Findings
PageSpeed Insights reported 14 passed accessibility audits. It also provided 10 additional items that require manual testing.

Some important items include:
- Interactive controls are keyboard focusable.
- The page has a logical tab order.
- Visual order follows DOM order.
- HTML5 landmark elements are used.
- Custom controls have associated labels.

# Manual Testing
I also tested my portfolio using only a keyboard.

I used the Tab key to move between navigation links and interactive elements. I used Shift + Tab to move backward and Enter to open links.

# Final Results
My portfolio received a 100/100 accessibility score on both mobile and desktop.

I also checked keyboard navigation to make sure visitors can browse the website without using a mouse.

# POUR Principles
I used the POUR principles to think about accessibility improvements on my portfolio website.

- Perceivable I checked that images have alternative text and that website content is easy to see and read.
- Operable: I tested keyboard navigation using Tab, Shift + Tab, and Enter without using a mouse.
- Understandable: I checked that navigation links, buttons, and page sections are clear and easy to understand.
- Robust: I used semantic HTML elements to help browsers and assistive technologies understand the website structure.
